# Atelier de la Bourse｜股市練習所

用**真實台股**的過去一年，零風險練習看盤、選股、讀財報的網頁學習遊戲。

> 一句話：拿 100 萬虛擬資金，回到 2026/9/7 收盤後，用真實發生過的未來 30 個交易日行情，練習在盤中下單。

## 給誰用

- 想開始投資、但不敢一開始就拿真錢試的學生與新手
- 看不懂「本益比、殖利率、毛利率、漲停」等術語的人
- 想知道「自己選股」和「買 ETF 放著」差多少的人

## 怎麼玩

1. 打開 `index.html`（或 GitHub Pages 網址），按「開始新的一局」。
2. 你站在 **2026/9/7 收盤後**，可以看 100 檔股票過去一年的日 K、財報與新聞。
3. 每個交易日 09:00–13:30 壓縮成 **5 分鐘**；可暫停（空白鍵）、1×／2×／4× 加速。
4. 盤中可下 **整股／零股、限價／市價** 單，手續費 0.1425%、證交稅 0.3%（ETF 0.1%）、漲跌幅 ±10% 都照台股規則。
5. 每天收盤有「收盤報」與一題術語小測驗；30 個交易日（2026/9/8 – 10/22）後看最終結算，跟 0050 和兩個 AI 機器人比較。

## 功能

| 區塊 | 內容 |
|---|---|
| 交易 | 100 檔真實上市股票與 ETF（半導體、記憶體、載板、AI 伺服器、電腦零組件、金融、航運…），盤中走勢、日 K、下單、委託、持股 |
| 財報 | 2026 上半年營收、毛利、營益、淨利、EPS、負債比，附白話解說 |
| 新聞 | 28 則查證過的真實市場事件（附來源），標在 K 線上 |
| 術語辭典 | 41 個金融術語，畫面上任何虛線字點了就跳出解釋 |
| AI 對手 | 兩個用 Q-learning 在過去一年資料上訓練的機器人：Rémy（追求報酬）、Claire（考慮風險、分散持股） |
| 結算 | 報酬率、最大回撤、交易成本、對比 0050、成就徽章、評等 A–D |

## 資料來源與誠實聲明

- 每日開、高、低、收、成交量：臺灣證券交易所 `MI_INDEX` 每日收盤行情（2025/9/8 – 2026/10/22）
- 本益比、殖利率、股價淨值比：臺灣證券交易所 `BWIBBU_d`（2026/9/7）
- 財報：臺灣證券交易所 OpenAPI（綜合損益表、資產負債表，2026 年上半年；金控營收以利息淨收益＋利息以外淨收益計）
- 歷史期間若有股票分割或除權息造成超過漲跌幅的跳空，之前的價格以還原股價調整
- **盤中逐分鐘跳動不是真實成交紀錄**，而是依當天真實的開高低收用隨機路徑產生（每次相同）。
- AI 機器人只用「前一天收盤以前」的資料做決定，隔天開盤才成交，不偷看未來。
- 本作品為課堂教學練習，**不構成任何投資建議**。

## 技術

純 HTML / CSS / JavaScript，無框架、無後端；資料約 0.8 MB，存檔放在瀏覽器 localStorage。

```
index.html
css/style.css
data/market.js     # 由 tools/build_data.py 產生
js/engine.js       # 時鐘、盤中走勢、撮合、手續費與稅
js/bots.js         # Q-learning 機器人與 0050 基準
js/charts.js       # Canvas 走勢圖、K 線、資產曲線
js/ui.js           # 畫面、晨報、收盤報、結算
js/glossary.js     # 術語與小測驗
tools/             # 資料整理腳本與新聞清單
```
